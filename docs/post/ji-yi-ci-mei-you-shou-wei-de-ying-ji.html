记一次没有收尾的应急

一、起因

  2026年9月9日17时32分，接到朋友求助，如图：

  刚开始我以为是鼠标坏了，但是朋友反馈说鼠标是新换的，所以排除这个选项。现在有点怀疑是不是护网哪个红队手底下没轻重，所以继续确认最近一两个月内有无接到协助护网或者攻防演练的通知，经确认还是没有，所以现在怀疑有被入侵。

二、排查

  先让朋友使用命令行netstat -ano查看有无恶意外联，但是对IP和PID检查发现没有任何异常，都是微软服务、微信、浏览器等常见IP,除了一个119.3.160.204:11111经核实，这是WPS的服务，所以就此作罢。本来下一步是让他在从日志入手看能不能抓到蛛丝马迹。但是这是朋友说他要下班了，能不能明天搞，我？？？？好家伙，你们公司还招人吗,我也想去~~~~~所以，只能现在先写个操作文档，然后然他明天去了在排查吧，总不能耽误人家下班。

三、后续工作

3.1、 检查安全登录日志

  1. 按 Win + R，输入 eventvwr.msc 并回车，打开“事件查看器”。
  2. 左侧展开 Windows 日志 → 点击 安全。
  3. 右侧点击“筛选当前日志”，在“事件 ID”框中输入 4624（成功登录），点击确定。
  4. 核对列表中的“登录时间”，重点关注深夜（如凌晨2-5点） 或明确不在电脑前的时间段。
  5. 双击可疑时间的记录，查看下方的“登录进程”：若显示 Network 或 RemotelyInteractive 则确定为网络远程入侵，若显示：Advapi则说明是正常，只是widows服务在后台执行。
  6. 检查日志是否被清除：在筛选框中输入事件ID 1102。如果查到该记录，说明系统日志被手动清空过，这本身就是重大危险信号。正常情况下是没有这个记录的

3.2、检查计划任务

  1. 按 Win + R，输入 taskschd.msc 打开“任务计划程序”。
  2. 点击左侧“任务计划程序库”，查看中间列表。重点排查：
    • 名称乱码（如 dskfje23）、纯数字。
    • 模仿系统更新名（如 SystemUpdater、JavaUpdate——非官方签名）。
    • 触发器为“当用户登录时”或“每隔X小时重复”的陌生任务。
  3. 处理：发现可疑项，右键 → “禁用”（先不删除，避免误删系统组件）。

3.3、 检查 PowerShell 历史记录（看黑客输过什么命令）

  1. 按 Win + R，复制以下路径并粘贴回车：
%userprofile%\AppData\Roaming\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
  1. 系统会用记事本打开该文件。
  2. 分析：查看是否有 Invoke-Expression、DownloadFile（下载文件）、netsh（改防火墙）、reg add（改注册表）等你看不懂的敏感命令。有则说明被命令行操控过。(如果都看不懂，则发给AI进行分析)

3.4、 检查系统服务(隐藏远控服务)

  1. 按 Win + R，输入 services.msc 并回车。
  2. 按名称排序，查找描述中包含 “Remote”、“Any”、“VNC” 的陌生服务。
  3. 注意：查看 Remote Desktop Services（远程桌面服务），若被修改为“自动”且状态为“正在运行”（默认应为“手动”或“禁用”），需警惕。右键可疑服务 → “停止”并“禁用”

3.5、 按修改时间排查木马本体文件

  1. 打开 此电脑（我的电脑）。
  2. 在右上角搜索框输入 *.exe。
  3. 点击顶部菜单栏的“修改日期”列，按日期降序排列（最新的在最前面）。
  4. 回忆你发现鼠标异常的大概时间点，查看该时间点前后生成的 .exe 文件。
  5. 鉴别：右键该文件 → 属性 → 数字签名。若无“Microsoft”等正规签名，按住 Shift + Delete 永久删除。

四、处置

  1. 如果发现有明显入侵痕迹，则对痕迹进行截图保留，然后立即备份重要文件，仅限于各类文档、表格、图片。不包括任何程序或.dll文件同时立即上报。
  2. 立即修改所有涉及登录的密码以防电脑Cookie被盗导致撞库。
  3. 使用火绒或者任何一个杀毒工具，进行全盘扫描并查杀然后重启。
  4. 如果查杀不掉，则在备份文件后，选择重装系统。
